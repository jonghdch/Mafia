# Mafia

브라우저에서 친구들과 하는 마피아 게임입니다. 사람이 모자라면 AI 플레이어가 빈자리를 채우고 AI 사회자가 밤과 낮의 결과를 테마에 맞는 이야기로 들려줍니다.

인공지능실습 강의 프로젝트이자 경진대회 출품작입니다.

## 상태

기획을 마치고 개발을 시작하는 단계입니다.

1. v1a: AI끼리 자동으로 대국하며 AI 플레이어 실력을 측정
2. v1b: 사람이 링크로 들어와 함께 하는 웹 게임

## 실행 준비

`.env.example`을 `.env`로 복사한 뒤 OpenAI API 키를 넣습니다. `.env`는 커밋하지 않습니다.
